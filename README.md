# MindShift

Mindfulness + CBT/DBT worksheet app (Kotlin, Jetpack Compose).

## Build
Open this folder in Android Studio → Gradle sync → Run.

## Tests
    ./gradlew testDebugUnitTest
    ./gradlew connectedDebugAndroidTest

## Contents
31 CBT/DBT/mindfulness worksheets · coping cards · breathing · meditation
timer · Leaves on a Stream · diary card · glossary · exposure ladder with
SUDS history · insights + heatmap · mood-responsive suggestions · 3 widgets ·
reminders with snooze/"Done today" · PDF reports · backup/restore · app lock ·
onboarding · full test suite.

Self-help tool only — not a substitute for professional care.
